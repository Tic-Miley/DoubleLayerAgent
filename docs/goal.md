## Context

`ParkingLotAgent`是一个有Agent提供数据分析的停车场。文件夹里提供了`README`等文档，以及完整的源代码。你可以通过文档了解其主要内容和功能。

## Goal

有一个两层级的Agent系统。

第二层有不同的物，例如停车场、医院、食堂、公园等等。这些物都能提供数据。一部分物通过数据接口直接给出数据，例如某停车场通过闸门记录场内车辆数，并通过HTTP接口提供这一int型数据；一部分物如`ParkingLogAgent`，搭载了一个Agent系统，能够灵活地分析请求和给出数据。

第一层有一个Agent。第一层记录了第二层所有物的描述，能够了解其能力，并额外索引物的位置、类型、功能等。第一层的Agent能够接收用户的数据整理分析请求，理解语义，选择需要的物，通过描述中的方法，调用接口或直接调用第二层的Agent，从而拿到每个物的数据，并在第一层进一步整理分析，最终为用户提供回答、绘制图表。

例如，用户发送“方圆五公里内的停车场中，最近三十天的新能源车占比？”，第一层的Agent能够找到第二层中的相关物（如停车场`ParkingLotAgent`），调用第二层的Agent，得到该停车场最近三十天的新能源车占比，在第一层中整合多个停车场提供的数据，最终总结回答，绘制图表，呈现给用户。

## Restriction

当前`ParkingLotAgent`是一个完整的前后端程序，可以供用户直接对话。你可以参考其中的Agent设计和UI/UX交互设计。不过，在本`DoubleLayerAgent`项目中，`ParkingLotAgent`只需要负责与第一层的Agent交互。

本`DoubleLayerAgent`项目主要目的是通过**仿真**，**验证技术可行性**，**实现演示效果**。主要技术点在物的调用、双层数据整理分析和双层Agent。其他不重要的部分均可以使用最简实现。
